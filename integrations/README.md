# Integrations layer

This directory is where RitualMesh connects to external systems.

Do not copy full external projects here.

Instead, create:

- adapters
- test scenarios
- scripts
- parsers
- validation tools

## Planned integrations

### mgen
- network traffic generation
- latency and throughput testing

### tracking
- node state tracking
- estimation experiments

Each integration should have its own subfolder.
